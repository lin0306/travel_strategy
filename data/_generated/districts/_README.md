# 边界缓存目录 —— 省 / 市行政区划轮廓。
#
# 🚨 合规红线：这里的每一条边界都必须来自腾讯 District 服务
#    （/ws/district/v1/getchildren?id={adcode}&get_polygon=1）。
#    **绝对禁止**引入任何第三方 GeoJSON、自制中国地图轮廓，
#    或 Wikipedia / Natural Earth / 各类开源数据集的中国边界。
#
#    原因：中国地图的行政区划边界涉及国家版图完整性 —— 台湾省、藏南地区、
#    南海诸岛、阿克赛钦的表达。第三方数据常把台湾单独成"国家"、按错误实控线
#    绘制藏南、或完全缺失南海诸岛。这类错误违反《地图管理条例》，
#    且在开源项目中极其常见（因为大量开源 GeoJSON 来自境外数据源）。
#
# 预期文件：
#   provinces.geo.json     全国 34 个省级边界
#   {adcode}.geo.json      某个省的市级边界（只生成已收录城市所在的省）
